# Video Production Quality Checklist

This checklist serves as a comprehensive framework to ensure video concepts are fully developed, technically precise, and optimized for Veo 3 generation with maximum viral potential. Work through each section systematically during the production process.

[[LLM: INITIALIZATION INSTRUCTIONS - VIDEO PRODUCTION CHECKLIST

2. Visual blueprint (from visual-director)
3. Engineered script (from script-writer)
4. Integrated production document (from production-coordinator)
5. Variations (if created)
6. Veo 3 technical specifications

IMPORTANT: If any core documents are missing, identify and obtain them before proceeding.

VALIDATION APPROACH:

1. Viral-First - Every element should contribute to shareability
2. Technical Precision - Specifications must be exact for consistency
3. Character Lock - Descriptions must be identical across all beats
4. Platform Native - Optimization for specific distribution channels
5. 8-Second Mastery - Constraints drive creativity

## 1. CONCEPT VALIDATION & STRATEGY

[[LLM: The foundation of viral video is strategic concept validation. As you review:

1. Verify the concept can work in 8-second beats
2. Check viral mechanics are built into the DNA
3. Ensure technical feasibility within Veo 3
4. Confirm platform optimization strategy
5. Validate character consistency approach]]

### 1.1 Core Concept

- [ ] Clear one-sentence pitch articulated
- [ ] Target emotion journey defined (start → end)
- [ ] Shareable hook identified with timestamp
- [ ] Success metrics established
- [ ] Platform primary and secondary identified

### 1.2 Viral Mechanics

- [ ] Universal emotion or experience present
- [ ] Unexpected moment placed strategically
- [ ] Quotable line under 10 words identified
- [ ] Visual spectacle moment defined
- [ ] Trend/challenge potential considered

### 1.3 Technical Feasibility

- [ ] Works with 1-2 characters maximum
- [ ] Achievable within 8-second beats
- [ ] Leverages Veo 3 strengths (lighting/physics/audio)
- [ ] Avoids Veo 3 limitations
- [ ] Complexity rated (simple/medium)

## 2. CHARACTER CONSISTENCY

[[LLM: Character consistency is CRITICAL for Veo 3. Check:

1. NEVER uses "same as beat 1" shortcuts
2. Complete descriptions in EVERY beat
3. Gender and age always specified
4. Descriptions are word-for-word identical
5. Visual lock documented]]

### 2.1 Character Description Quality

- [ ] Complete physical appearance documented
- [ ] Gender explicitly specified (male/female)
- [ ] Exact age provided (not range)
- [ ] Clothing described in detail
- [ ] Distinguishing features noted

### 2.2 Consistency Verification

- [ ] Beat 1 description complete
- [ ] Beat 2 description IDENTICAL to Beat 1
- [ ] Beat 3 description IDENTICAL to Beat 1 & 2
- [ ] NO shortcuts or references used
- [ ] Character bible created and locked

### 2.3 Voice Consistency

- [ ] Voice characteristics defined
- [ ] Speech patterns documented
- [ ] Emotional range specified
- [ ] Delivery style consistent
- [ ] Authenticity markers included

## 3. SCRIPT & DIALOGUE ENGINEERING

[[LLM: Natural dialogue within constraints is crucial. Validate:

1. NO ALL CAPS in dialogue (prevents letter-by-letter audio)
2. Word counts within 8-second limits
3. Sounds natural when spoken aloud
4. Viral moment is quotable
5. Performance notes are specific]]

### 3.1 Dialogue Formatting

- [ ] NO ALL CAPS in spoken dialogue
- [ ] Visual text/logos caps acceptable
- [ ] Emphasis through delivery notes only
- [ ] Natural capitalization throughout
- [ ] Contractions used appropriately

### 3.2 Timing Constraints

- [ ] Solo speaker: 12-18 words maximum
- [ ] With pauses: 10-15 words
- [ ] Two speakers: 8-10 words each
- [ ] Every word advances story
- [ ] Breathing space allocated

### 3.3 Performance Specifications

- [ ] Delivery notes specific
- [ ] Emphasis words marked
- [ ] Energy progression defined
- [ ] Emotional arc clear
- [ ] Physical actions noted

## 4. VISUAL EXCELLENCE

### 4.1 Camera Specifications

- [ ] Lens choice specified (mm and f-stop)
- [ ] Movement precisely defined
- [ ] Position and height noted
- [ ] Focus instructions clear
- [ ] Platform framing considered

### 4.2 Lighting Design

- [ ] Key light position and temperature
- [ ] Fill ratio specified
- [ ] Rim light if needed
- [ ] Practicals identified
- [ ] Evolution mapped for transformations

### 4.3 Color Science

- [ ] Hex codes provided
- [ ] Palette consistency verified
- [ ] Grade approach defined
- [ ] Skin tones specified
- [ ] Environmental colors locked

## 5. TRANSFORMATION SPECIFICATIONS (If Applicable)

### 5.1 Transformation Type

- [ ] Category selected (logo/unboxing/environment/particle)
- [ ] Keywords match transformation style
- [ ] Timing breakdown precise
- [ ] Stage transitions defined
- [ ] Physics behavior specified

### 5.2 Choreography Precision

- [ ] 0.0-1.5s: Trigger phase defined
- [ ] 1.5-4.0s: Transformation phase specified
- [ ] 4.0-6.5s: Formation phase detailed
- [ ] 6.5-8.0s: Stabilization complete
- [ ] Audio sync points identified

### 5.3 Material Physics

- [ ] Particle behavior described
- [ ] Surface properties defined
- [ ] Physics accuracy verified
- [ ] Convergence patterns specified
- [ ] Environmental response planned

## 6. AUDIO ARCHITECTURE

### 6.1 Dialogue Track

- [ ] Level at -6dB peak
- [ ] Processing specified
- [ ] Panning centered
- [ ] Timing exact
- [ ] Delivery noted

### 6.2 Audio Layers

- [ ] Ambient: -18dB continuous
- [ ] SFX: Timed and leveled
- [ ] Music: -15dB if present
- [ ] Spatial positioning planned
- [ ] Transitions designed

### 6.3 Transformation Audio

- [ ] Sync points frame-accurate
- [ ] Evolution matches visual
- [ ] Spatial movement considered
- [ ] Dynamic range appropriate
- [ ] Mix clarity verified

## 7. KEYWORDS & PLATFORM

### 7.1 Keywords Validation

- [ ] Core present: "16:9", "no text", "8 seconds"
- [ ] Style keywords match approach
- [ ] Complete array in all outputs
- [ ] Consistency across variations
- [ ] Platform-specific keywords added

### 7.2 Platform Optimization

- [ ] YouTube: 16:9 native, thumbnail identified
- [ ] TikTok: 9:16 crop safe, 1.5s hook
- [ ] Instagram: Multiple formats considered
- [ ] LinkedIn: Professional tone verified
- [ ] Loop points identified where applicable

## 8. BEAT INTEGRATION

### 8.1 Flow Architecture

- [ ] Energy curve mapped
- [ ] Transitions engineered
- [ ] Audio continuity designed
- [ ] Visual consistency verified
- [ ] Emotional journey smooth

### 8.2 Variation Strategy

- [ ] Test hypothesis clear
- [ ] Constants vs variables defined
- [ ] Character unchanged across variations
- [ ] Keywords appropriate per variation
- [ ] Success metrics for each variation
