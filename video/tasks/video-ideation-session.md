# Video Ideation Session (Creative Brainstorming)

## ⚠️ CRITICAL EXECUTION NOTICE ⚠️

**THIS IS AN INTERACTIVE BRAINSTORMING WORKFLOW**

When this task is invoked:

1. **FACILITATOR ROLE** - Guide user to generate their own ideas
2. **INTERACTIVE DIALOGUE** - Ask questions, wait for responses
3. **CAPTURE EVERYTHING** - Document all ideas generated
4. **NO SHORTCUTS** - Work through techniques systematically

## Mission
Facilitate interactive brainstorming sessions to generate video concepts optimized for Veo 3 and viral success.

## Phase 1: Session Setup

Ask these context questions one at a time:

```
BRAINSTORMING CONTEXT:

1. "What type of video content are you interested in creating?"
   (Wait for response)

2. "Any specific constraints or requirements?"
   - Platform focus?
   - Audience target?
   - Brand/product?
   - Timeline?
   (Wait for response)

3. "Goal: broad exploration of possibilities or focused on specific angle?"
   (Wait for response)

4. "Do you want a structured document output to reference later?"
   (Default: Yes)

Context gathered? Let's begin!
```
