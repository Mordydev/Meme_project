# Veo 3 Video Production System

## Overview

A comprehensive agent-based system for creating optimized video content for Google Veo 3, transforming ideas into viral-ready 8-second beats through structured workflows and strategic optimization.

## System Architecture

### 4 Specialized Agents

#### 1. Video Strategist (`/video-strategist`)
- **Role**: Strategic Video Concept Architect & Creative Mentor
- **Focus**: Concept validation, viral mechanics, platform optimization
- **Key Tasks**:
  - Validate video concepts
  - Design beat structures
  - Analyze viral potential
  - Select transformation types

#### 2. Visual Director (`/visual-director`)
- **Role**: Master Cinematographer & Visual Excellence Architect
- **Focus**: Cinematography, transformation design, lighting, material physics
- **Key Tasks**:
  - Design visual blueprints
  - Choreograph transformations
  - Create lighting plots
  - Ensure character consistency

#### 3. Script Writer (`/script-writer`)
- **Role**: Script Engineering Expert & Natural Dialogue Architect
- **Focus**: Natural dialogue, timing precision, audio architecture
- **Key Tasks**:
  - Engineer video scripts
  - Optimize 8-second timing
  - Design audio layers
  - Create authentic dialogue

#### 4. Production Coordinator (`/production-coordinator`)
- **Role**: Production Integration Expert & Quality Assurance Specialist
- **Focus**: Beat integration, variation creation, final polish
- **Key Tasks**:
  - Integrate all beats
  - Create A/B/C variations
  - Validate quality
  - Prepare platform versions

## Core Workflows

### Manual Production Pipeline

1. **Strategic Ideation** → Video Strategist
   - Validate concept feasibility
   - Identify viral mechanics
   - Design beat structure

2. **Visual Design** → Visual Director
   - Create cinematography specs
   - Design transformations
   - Lock character descriptions

3. **Script Engineering** → Script Writer
   - Write natural dialogue
   - Optimize timing
   - Design audio architecture

4. **Production Assembly** → Production Coordinator
   - Integrate all elements
   - Create variations
   - Final quality checks

5. **Final Enhancement** → Production Coordinator
   - Apply strategic polish
   - Select best variations
   - Production validation

### 🚀 YOLO Mode - Fully Automated Pipeline

**One command completes everything from concept to final beats:**

```
/video-strategist
*yolo "your concept here"
```

YOLO Mode features:
- **Zero intervention** after initial input
- **Automatic agent handoffs** between all 4 agents
- **Self-correcting validation** with up to 3 auto-fix attempts
- **95%+ quality guarantee** via comprehensive checklist
- **Platform optimization** auto-detected or specified
- **Best practices applied** automatically
- **Complete in minutes** not hours

#### YOLO Mode Process:
1. Analyzes concept and auto-selects content type
2. Generates optimal visual design
3. Engineers natural dialogue within constraints
4. Integrates and creates variations
5. Applies enhancement and polish
6. **Runs quality checklist** and auto-fixes issues
7. Delivers production-ready Veo 3 beats

#### Self-Correction Features:
- **Character consistency** - Auto-copies descriptions to all beats
- **Dialogue formatting** - Fixes ALL CAPS issues automatically
- **Missing keywords** - Adds required keywords
- **Timing issues** - Reduces word count if over 8 seconds
- **Technical specs** - Fills incomplete specifications
- **Platform optimization** - Applies correct settings

If validation score < 95%, YOLO mode automatically:
1. Identifies specific issues
2. Applies targeted fixes
3. Re-validates
4. Repeats up to 3 times
5. Only flags for manual review if still failing

## Critical Requirements

### Character Consistency
- **NEVER** use shortcuts like "same as beat 1"
- Include complete description in EVERY beat
- Specify gender and exact age always
- Copy descriptions word-for-word

### Audio Formatting
- **NO ALL CAPS** in dialogue (prevents letter-by-letter reading)
- Visual text/logos can have CAPS
- Use delivery notes for emphasis

### Keywords System
**Core Requirements (All Projects):**
- "16:9"
- "no text"
- "8 seconds"

**Style Variables:**
- Elegant: ["premium aesthetic", "fluid assembly", "soft lighting"]
- Dynamic: ["high energy", "explosive motion", "dramatic lighting"]
- Mystical: ["ethereal motion", "magical atmosphere", "otherworldly"]
- Technical: ["precise motion", "mechanical assembly", "clinical lighting"]

## 8-Second Beat Constraints

### Word Limits
- Solo speaker: 12-18 words
- With pauses: 10-15 words
- Two speakers: 8-10 words each
- With action: 10-15 words max

### Timing Precision
- 0-2s: Hook establishment
- 2-6s: Development/transformation
- 6-8s: Resolution/hero shot

## Platform Optimization

### YouTube (16:9 Native)
- Full frame composition
- Thumbnail at 0:02
- Complete story arc

### TikTok (9:16 Crop)
- Center 60% critical action
- Hook in 1.5 seconds
- Loop potential

### Instagram
- Reels: 9:16 vertical
- Feed: 1:1 center square
- Stories: UI space considered
