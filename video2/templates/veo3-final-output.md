## 🚨 TROUBLESHOOTING GUIDE

### Common Generation Issues & Fixes

| Problem | Cause | Solution |
|---------|-------|----------|
| **Character looks different between beats** | Incomplete character descriptions | Use IDENTICAL full description in every beat |
| **Dialogue sounds robotic/spelled out** | ALL CAPS in spoken dialogue | Change "THIS IS GREAT!" to "this is great!" |
| **Inconsistent visual style** | Different keywords between beats | Maintain exact same keywords across all beats |
| **Poor lighting/flat image** | Missing lighting specifications | Include key/fill/rim lights with temperatures & ratios |
| **Generic background** | Underspecified environment | Add architecture, scale, props, atmospheric details |
| **No emotional impact** | Missing action timing breakdown | Include precise 0-2s, 2-4s, 4-6s, 6-8s action timing |
| **Low viral potential** | Weak viral element identification | Identify specific moment and universal appeal |
| **Generation fails** | Too complex or unclear prompts | Simplify while maintaining detail completeness |

### Pre-Generation Checklist (Use This!)
1. ✅ Read character description from Beat 1 aloud
2. ✅ Copy EXACT same description to Beat 2 & 3
3. ✅ Check no ALL CAPS in dialogue (except visual logos)
4. ✅ Verify all camera specs include lens, aperture, position, movement
5. ✅ Confirm lighting has key/fill/rim with temperatures
6. ✅ Validate environment has architecture, scale, props
7. ✅ Check action timing broken into 2-second segments
8. ✅ Ensure keywords identical across all beats
