# Video Producer Production Checklist

This checklist serves as a comprehensive framework to validate visual design, beat integration, variations, and final production readiness for Veo 3 generation. The Video Producer should systematically work through each item before delivering final prompts.

[[LLM: INITIALIZATION INSTRUCTIONS - VIDEO PRODUCER CHECKLIST

Before proceeding with this checklist, ensure you have access to:

1. Story architecture - Complete beat structure from Video Strategist
2. Visual specifications - All camera, lighting, and composition details
3. Character descriptions - Complete character bible with consistency notes
4. Script with timing - Dialogue and audio specifications
5. Variation plans - If A/B/C testing is planned
6. Platform requirements - Export specifications

IMPORTANT: This checklist assumes the Video Strategist phase is complete. If foundational elements are missing, return to strategy phase first.

VALIDATION APPROACH:

1. Visual Precision - Every specification must be exact
2. Character Consistency - Word-for-word descriptions required
3. Technical Accuracy - Professional cinematography language
4. Audio Safety - NO ALL CAPS in dialogue
5. Platform Ready - Optimized for all target channels

EXECUTION MODE:
Ask the user if they want to work through the checklist:

- Section by section (interactive mode) - Review each section, present findings, get confirmation before proceeding
- All at once (comprehensive mode) - Complete full analysis and present comprehensive report at end]]

## 1. VISUAL DESIGN SPECIFICATIONS

[[LLM: Visual precision drives consistency. As you review this section:

1. Verify all camera specifications are complete
2. Check lighting setups are professionally defined
3. Ensure composition accounts for platform crops
4. Validate color science is specified
5. Confirm all visual elements support the story]]

### 1.1 Camera Specifications

- [ ] Lens selection specified (24mm/35mm/50mm/85mm)
- [ ] Aperture settings defined (f-stop values)
- [ ] Camera position and height noted
- [ ] Movement precisely described (distance, time, easing)
- [ ] Frame rate confirmed (24fps standard)

### 1.2 Camera Choreography (Transformations)

- [ ] Start position exactly defined
- [ ] Movement path with timing breakdown
- [ ] Sync points with transformation stages
- [ ] End position for hero shot
- [ ] Continuous shot feasibility verified

### 1.3 Lighting Design

- [ ] Key light: temperature, position, intensity
- [ ] Fill light: ratio to key specified
- [ ] Rim light: if applicable, positioned
- [ ] Practicals: motivated and visible sources
- [ ] Atmosphere: haze percentage if used

### 1.4 Composition & Framing

- [ ] Rule of thirds applied appropriately
- [ ] Headroom and lead room specified
- [ ] Depth layers defined (fore/mid/background)
- [ ] Platform safe areas considered
- [ ] 9:16 and 1:1 crops validated

### 1.5 Color Science

- [ ] Primary palette with hex codes
- [ ] Skin tone specifications
- [ ] Environment colors defined
- [ ] Color grade style specified
- [ ] Consistency across beats verified

## 2. CHARACTER VISUAL CONSISTENCY

[[LLM: Character consistency is ABSOLUTE. Check:

1. NEVER "same as beat 1" shortcuts
2. Complete descriptions in EVERY beat
3. Gender and age always specified
4. Descriptions copied word-for-word
5. Continuity notes for changes]]

### 2.1 Character Descriptions

- [ ] Full name included every time
- [ ] Age as exact number (e.g., "28-year-old")
- [ ] Gender specified (male/female)
- [ ] Complete physical description
- [ ] Clothing exactly described

### 2.2 Appearance Details

- [ ] Hair: style, length, color specified
- [ ] Build: specific description
- [ ] Distinguishing features noted
- [ ] Accessories listed
- [ ] Makeup/grooming described

### 2.3 Consistency Verification

- [ ] Descriptions identical across all beats
- [ ] NO shortcuts or references used
- [ ] Continuity changes documented
- [ ] Character ID system used
- [ ] Copy-paste verification done

## 4. AUDIO SPECIFICATIONS

[[LLM: Audio excellence requires precision. Check:

1. NO ALL CAPS in dialogue (unless intentional)
2. Levels properly specified
3. Spatial audio considered
4. Sync points exact
5. Layers balanced]]

### 4.1 Dialogue Verification

- [ ] NO ALL CAPS in character speech
- [ ] Visual text/logos can use ALL CAPS
- [ ] Natural capitalization used
- [ ] Letter-by-letter reading avoided
- [ ] Delivery notes included

### 4.2 Audio Levels

- [ ] Dialogue: -6dB peak specified
- [ ] Ambient: -18dB consistent
- [ ] SFX: -12dB average
- [ ] Music: -15dB under dialogue
- [ ] All levels documented

### 4.3 Audio Synchronization

- [ ] Dialogue timing precise
- [ ] SFX sync points marked
- [ ] Music cues specified
- [ ] Transformation audio mapped
- [ ] Spatial positioning noted
