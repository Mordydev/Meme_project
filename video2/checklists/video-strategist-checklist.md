# Video Strategist Requirements Checklist

This checklist serves as a comprehensive framework to ensure video concepts are thoroughly validated, story architecture is complete, and scripts are optimized for Veo 3 generation. The Video Strategist should systematically work through each item during the concept development process.

[[LLM: INITIALIZATION INSTRUCTIONS - VIDEO STRATEGIST CHECKLIST

Before proceeding with this checklist, ensure you have access to:

1. Concept documentation - Any initial ideas or briefs
2. Story architecture - Beat-by-beat structure if created
3. Script drafts - Dialogue and timing specifications
4. Transformation designs - If applicable to the project
5. Keyword strategy - For consistency across beats
6. Platform requirements - Target distribution channels

IMPORTANT: If starting from scratch, work through sections progressively. If reviewing existing work, gather all available documents first.

VALIDATION APPROACH:

1. Technical Feasibility - Every concept must work within Veo 3's constraints
2. Viral Potential - Engineer shareability from the start
3. Character Consistency - Absolute precision in descriptions
4. Platform Optimization - Native to target channels
5. 8-Second Mastery - Maximum impact within time limits

EXECUTION MODE:
Ask the user if they want to work through the checklist:

- Section by section (interactive mode) - Review each section, present findings, get confirmation before proceeding
- All at once (comprehensive mode) - Complete full analysis and present comprehensive report at end]]

## 1. CONCEPT VALIDATION & FEASIBILITY

[[LLM: The foundation of any successful video is a validated concept. As you review this section:

1. Verify the concept can be executed in 8-second beats
2. Check that complexity is within Veo 3's capabilities
3. Ensure viral mechanics are built in, not added later
4. Confirm the target audience is specific and reachable
5. Validate that success metrics are measurable]]

### 1.1 Core Concept Definition

- [ ] Clear one-sentence concept articulation
- [ ] Target emotion/feeling identified
- [ ] Specific audience defined (not "everyone")
- [ ] Share trigger mechanism identified
- [ ] Success metrics defined (views, shares, engagement)

### 1.2 Technical Feasibility

- [ ] Concept works within 8-second beat constraints
- [ ] Maximum 1-2 characters per beat
- [ ] Single location per beat (or seamless transformation)
- [ ] Visual hook achievable in first 2 seconds
- [ ] Leverages Veo 3 strengths (lighting/physics/audio)

### 1.3 Red Flag Detection

- [ ] No complex multi-character interactions required
- [ ] No extensive VFX beyond Veo 3 capabilities
- [ ] No dependency on perfect timing beyond 8 seconds
- [ ] No need for specific brand logos or text overlays
- [ ] Concept has clear visual anchors (not abstract)

### 1.4 Viral Mechanics

- [ ] Universal emotion or experience present
- [ ] Unexpected moment or twist included
- [ ] Quotable line identified (under 10 words)
- [ ] Screenshot-worthy visual moment planned
- [ ] Trend potential or recreatability considered

## 2. CONTENT TYPE & STRUCTURE

[[LLM: Content type selection drives all subsequent decisions. Validate:

1. Content type matches concept goals
2. Structure supports narrative needs
3. Beat architecture is appropriate
4. Transformation type (if applicable) is feasible
5. Keywords align with content category]]

### 2.1 Content Category Selection

- [ ] Content type clearly identified (Entertainment/Animation/Interview/Commercial/Transformation)
- [ ] Viral mechanism for category understood
- [ ] Complexity level appropriate (simple/medium)
- [ ] Best practices for category documented
- [ ] Platform alignment considered

### 2.2 Beat Structure Architecture

- [ ] Beat structure selected (Continuous/Compilation/Hybrid/Transformation)
- [ ] Each beat purpose clearly defined
- [ ] Beat transitions planned
- [ ] Timing breakdown precise (0.0-8.0s)
- [ ] Keywords strategy developed for consistency

### 2.3 Transformation Design (If Applicable)

- [ ] Transformation type selected (logo-to-product/unboxing/environment/particle)
- [ ] Stage timing precisely mapped (0.0-1.5s, 1.5-3.0s, etc.)
- [ ] Camera choreography planned
- [ ] Particle/material physics defined
- [ ] Audio synchronization points marked

## 3. CHARACTER BIBLE & CONSISTENCY

[[LLM: Character consistency is ABSOLUTE. Check:

1. Complete descriptions exist for every character
2. Descriptions are copied word-for-word across beats
3. Gender and age are specified every time
4. Voice characteristics are defined
5. No shortcuts or references used]]

### 3.1 Character Documentation

- [ ] Complete physical description created
- [ ] Age specified as exact number
- [ ] Gender clearly stated (male/female)
- [ ] Clothing described in detail
- [ ] Distinguishing features noted

### 3.2 Voice Profile

- [ ] Tone and pitch defined
- [ ] Speaking pace specified
- [ ] Accent noted if applicable
- [ ] Vocal quirks documented
- [ ] Emotional range mapped

### 3.3 Consistency Verification

- [ ] NEVER uses "same as beat 1" shortcuts
- [ ] Descriptions identical across all beats
- [ ] Character ID system implemented
- [ ] Continuity notes for each beat
- [ ] Movement and gesture patterns defined

## 4. SCRIPT ENGINEERING

[[LLM: Scripts must work within tight constraints. Verify:

1. Word counts are within limits
2. Dialogue sounds natural when spoken
3. NO ALL CAPS in dialogue (unless intentional)
4. Timing is precisely specified
5. Audio layers are balanced]]

### 4.1 Dialogue Optimization

- [ ] Maximum 12-18 words per 8-second beat (solo)
- [ ] Maximum 8-10 words each (two speakers)
- [ ] Natural speech patterns used
- [ ] Contractions and fragments where appropriate
- [ ] NO ALL CAPS in dialogue text

### 4.2 Timing Precision

- [ ] Exact timing for each line specified
- [ ] Pauses and breaths allocated
- [ ] SFX timing marked precisely
- [ ] Music cues noted
- [ ] Total duration exactly 8.0 seconds

### 4.3 Audio Architecture

- [ ] Dialogue level: -6dB peak
- [ ] Ambient: -18dB consistent
- [ ] SFX: -12dB average
- [ ] Music: -15dB under dialogue
- [ ] Spatial audio considered

### 4.4 Performance Notes

- [ ] Delivery style specified for each line
- [ ] Emotional progression mapped
- [ ] Energy levels defined (1-10 scale)
- [ ] Physical actions synchronized
- [ ] Viral moment emphasized
