# The Veo 3 Video Creation System: Enhanced Edition
## From Strategy to Viral Success in 6 Optimized Prompts

### System Architecture
A comprehensive 6-prompt system engineered for Google Veo 3's capabilities, transforming ideas into viral-worthy content through structured, JSON-inspired precision.

### Veo 3 Technical Specifications

#### Core Capabilities
- **Native Audio**: Synchronized dialogue, SFX, ambience, music in one generation
- **Visual Quality**: Photorealistic humans, accurate physics, cinematic lighting
- **Duration**: 8-second clips (optimal for social micro-narratives)
- **Resolution**: 720p native, 16:9 aspect ratio
- **Frame Rate**: 24fps standard (cinematic quality)

#### Optimal Parameters
- **Characters**: 1-2 subjects maximum for consistency
- **Camera Work**: Professional cinematography language (35mm, dolly, tracking)
- **Audio Layers**: 4 concurrent tracks (dialogue, ambient, SFX, music)
- **Lighting**: Complex motivated setups with specific color temperatures
- **Consistency**: Seed management for character continuity

#### Critical Constraints
- **Subtitles**: Must explicitly prevent with "(no subtitles)"
- **Duration**: Exactly 8 seconds per generation
- **Complexity**: Simple scenes generate more reliably
- **Cost**: 100 credits per high-quality clip

### Enhanced Prompt Structure

Each prompt now incorporates:
1. **Structured Data Format**: JSON-inspired organization for clarity
2. **Technical Precision**: Specific measurements, timings, and settings
3. **Audio Architecture**: Layered sound design with dB levels
4. **Visual Rules**: Explicit constraints and requirements
5. **Character Bible**: Consistent descriptions with reference codes

### Success Metrics

**Technical Quality**
- Consistent character model across beats
- Audio sync accuracy >95%
- No unwanted text overlays
- Smooth transitions between beats

**Viral Indicators**
- First 2-second hook strength
- Shareable moment clarity
- Platform-native optimization
- Engagement rate >15%

### Critical Requirements (NEW)

**ALL CAPS Audio Warning:**
- ALL CAPS DIALOGUE = T H I S (letter by letter audio reading)
- VISUAL text/logos like "GEMINI" are fine (seen, not spoken)
- Only affects spoken character dialogue

**Character Consistency Rules:**
- NEVER use shortcuts ("same as beat 1")
- Include complete description in EVERY beat
- Specify gender (male/female) and exact age
- Copy descriptions word-for-word across beats

### System Requirements

**Before Starting:**
- Clear concept with 8-second beat structure
- Character descriptions (physical + voice)
- Platform distribution strategy
- Success metrics defined

**During Creation:**
- Maintain exact character descriptions
- Use specific technical values
- Layer audio intentionally
- Document successful seeds

**After Generation:**
- Verify consistency across beats
- Check audio sync and levels
- Confirm no prohibited elements
- Test platform crops
