# Veo 3 Video Creation System

## Overview
A comprehensive agent-based system for creating viral-ready videos optimized for Google Veo 3's 8-second format. Features complete automation with YOLO mode, dual-agent validation, and self-correcting workflows that transform ideas into production-ready prompts.

## 🚀 YOLO Mode (NEW!)
**Complete automation from concept to final Veo 3 prompts with zero user intervention.**

### Quick Start with YOLO
```bash
1. Launch: /video-strategist
2. Run: *yolo-complete
3. Input: "Create a video about [your concept]"
4. Wait: ~5-10 minutes
5. Receive: Complete Veo 3 production package
```

### YOLO Features
- **Full Automation**: Complete workflow executed without user input
- **Enhanced Tasks**: All 6 original prompts integrated with advanced capabilities
- **Self-Correction**: Automatically fixes issues found during validation
- **Intelligent Defaults**: Makes best-practice decisions automatically
- **Dual Validation**: Runs both strategy and production checklists
- **Quality Assurance**: Achieves 85%+ strategy, 90%+ production scores
- **Advanced Features**: Material physics, audio orchestration, viral optimization

### Auto-Fix Capabilities
YOLO mode automatically corrects:
- Dialogue exceeding word limits (auto-trim)
- ALL CAPS in dialogue (converts to normal case)
- Missing required keywords (auto-adds)
- Incomplete character descriptions (generates details)
- Timing issues (adjusts to exactly 8.0s)
- Character consistency problems (enforces identical descriptions)

## Critical Requirements

### Character Consistency
- **NEVER** use "same as beat 1" shortcuts
- Include complete character description in EVERY beat
- Specify gender and exact age every time
- Copy descriptions word-for-word for consistency
- YOLO mode enforces this automatically

### Audio Formatting
- **NO ALL CAPS** in dialogue (reads letter-by-letter)
- Visual text/logos in ALL CAPS are fine
- Check every dialogue line before generation
- YOLO mode auto-converts to safe format

### Technical Specifications
- Duration: Exactly 8 seconds per beat
- Resolution: 1280x720 (720p)
- Aspect Ratio: 16:9 native
- Frame Rate: 24fps
- Keywords: Always include "16:9", "no text", "8 seconds"
