# Product Context: Success Kid Community Platform

## 1. Problem Solved

The project aims to provide long-term utility and a sustainable ecosystem for the Success Kid (SKC) meme coin, moving beyond speculative value. It creates a community platform where engagement is rewarded.

## 2. Core Mechanism: Dual-Token Economy

*   **SKC Token:** The primary cryptocurrency (7 billion total supply). Value derived from market dynamics and platform utility.
*   **Success Points (SP):** An on-platform utility token earned through various forms of engagement (content creation, interaction, achievements, etc.). SP are redeemable for SKC (100 SP = 10 SKC), creating a direct link between platform activity and token value.

## 3. Target User Experience

*   **Engaging:** Users are incentivized to participate actively through points and achievements.
*   **Rewarding:** Platform activity translates into tangible value (SP -> SKC).
*   **Seamless:** Easy interaction across different platform sections (Dashboard, Community, Rewards, Market, Profile).
*   **Informative:** Clear visibility into points balance, achievements, market data, and community activity.
*   **Secure:** Users trust the platform with their data, points, and potential wallet connections.

## 4. Key Platform Areas (Backend Perspective)

*   **Dashboard:** Aggregated view of user status, points, achievements, market highlights, activity feed.
*   **Community:** Content creation (posts, comments), feeds (global, following), reactions, user profiles, drafts.
*   **Rewards:** Points system details, achievement tracking, redemption mechanism (SP to SKC).
*   **Market:** SKC token price, market stats (cap, volume), transaction history, milestone tracking.
*   **Create/Profile/Settings:** Content creation interface, user profile management, application settings, media uploads.
