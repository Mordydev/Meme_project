# NEMO Runner Product Context

## Problems Solved
1. **Engagement Gap**: Provides an interactive gameplay experience that enhances token holder engagement beyond passive holding
2. **Community Expansion**: Creates a new entry point for users who enjoy casual gaming to discover the Pixarfication ecosystem
3. **Value Proposition**: Establishes tangible rewards for active participation through skill-based competition
4. **Retention Challenge**: Drives daily user returns through limited gameplay sessions and daily leaderboards
5. **Cross-Platform Barriers**: Delivers consistent experience across desktop and mobile devices without requiring app installation

## User Experience Goals
1. **Immediate Engagement**: Players should be able to start playing within seconds of visiting
2. **Intuitive Controls**: Game mechanics that are easy to learn but difficult to master
3. **Rewarding Progression**: Clear sense of improvement and achievement with distance milestones
4. **Visual Delight**: Vibrant underwater world that captures the Finding Nemo aesthetic
5. **Smooth Performance**: Consistent frame rates and responsive controls across device types
6. **Social Connection**: Leaderboards and score sharing that foster community competition
7. **Transparent Systems**: Clear understanding of scoring mechanisms and reward distribution
8. **Accessible Depth**: Progressive complexity that caters to both casual and competitive players

## User Personas

### Casual Crypto Fan (Alex)
- **Profile**: 25-35 years old, has some crypto holdings but not deeply technical
- **Motivation**: Entertainment and nostalgia for childhood animation
- **Behavior**: Plays a few games daily, shares scores occasionally
- **Goals**: Have fun, potentially win small rewards, connect with community
- **Needs**: Simple onboarding, clear instructions, forgiving gameplay

### Competitive Gamer (Jordan)
- **Profile**: 18-28 years old, experienced in gaming, moderately active in crypto
- **Motivation**: Leaderboard ranking and SOL rewards
- **Behavior**: Plays maximum daily attempts, strategizes optimal routes
- **Goals**: Achieve top rankings, maximize reward earnings, gain community recognition
- **Needs**: Fair competition, skill-based mechanics, detailed performance stats

### Pixarfication Community Member (Morgan)
- **Profile**: 22-40 years old, already engaged in Pixarfication ecosystem
- **Motivation**: Expanding involvement in the ecosystem, supporting new initiatives
- **Behavior**: Regularly checks both visual content and game, promotes within community
- **Goals**: Participate in ecosystem growth, collect achievements, strengthen community
- **Needs**: Integration with existing tokens, cross-promotion, consistent experience

### Mobile Crypto User (Riley)
- **Profile**: 20-40 years old, primarily uses mobile for crypto and gaming
- **Motivation**: Accessible gameplay during commutes or short breaks
- **Behavior**: Plays in short sessions multiple times per day when available
- **Goals**: Enjoyable mobile experience without technical barriers
- **Needs**: Touch-optimized controls, performance on mid-range devices, minimal data usage

## Business Value Proposition

### For Players
1. Free-to-play endless runner with engaging underwater theme
2. Skill-based competition with real cryptocurrency rewards
3. Daily gameplay limits that respect player time while encouraging regular engagement
4. Connection to the broader Pixarfication community and aesthetic

### For Pixarfication Ecosystem
1. Expansion vector to attract gaming-oriented crypto users
2. Increased daily active user metrics through gameplay engagement
3. Enhanced token utility through game integration
4. Cross-promotion potential between visual content and interactive experience
5. New narrative dimensions through character-driven gameplay

### For Developers/Stakeholders
1. Scalable platform for future feature additions and game modes
2. Data collection on user preferences and behavior patterns
3. Community building through competitive and collaborative features
4. Potential for sustainable growth through player retention and word-of-mouth

## How the Product Should Work

### Player Journey
1. **Discovery**: User finds the game through Pixarfication community, social media, or word-of-mouth
2. **First Play**: Anonymous user gets one play session to experience the game
3. **Registration**: After first play, user is prompted to create an account for more plays
4. **Daily Engagement**: Registered user returns for daily 10-game allocation
5. **Competition**: Player views leaderboards and aims to improve ranking
6. **Community**: Shares scores, strategies, and participates in community events
7. **Rewards**: Top performers receive SOL distributions on leaderboard reset intervals

### Core Interactions
1. **Movement Controls**: 
   - Desktop: Arrow keys for directional movement, space for power-ups
   - Mobile: Swipe gestures for movement, tap for power-ups

2. **Obstacle Avoidance**:
   - Navigate around static obstacles like coral and rocks
   - Time movements to avoid dynamic obstacles like predator fish and jellyfish
   - Respond to pattern-based obstacles with rhythm and timing

3. **Collectible Gathering**:
   - Collect bubbles of varying sizes for points
   - Obtain power-ups for temporary advantages
   - Navigate toward bonus point opportunities

4. **Progression System**:
   - Automatically increasing speed and difficulty over distance
   - Introduction of new obstacle types and environments as distance increases
   - Score multipliers for skilled play (near misses, pattern completion)

5. **Social Features**:
   - Leaderboard viewing and ranking information
   - Personal best tracking and improvement metrics
   - Score sharing to social platforms
   - Achievement unlocks and milestones

### Performance Expectations
- Load time under 5 seconds on average connections
- Consistent 30+ FPS on mid-range mobile devices
- 60+ FPS on desktop and high-end mobile
- Input response time under 100ms
- Collision detection accuracy with appropriate forgiveness
- Seamless animation transitions between movement states
- Balanced difficulty progression that extends average session length to 3-5 minutes
