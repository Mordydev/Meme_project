# Backend

Fastify API service for the Success Kid Platform.

## Getting Started

### Development

```bash
# From the root of the monorepo
pnpm dev --filter=backend

# Or from this directory
pnpm dev
```

### Building

```bash
# From the root of the monorepo
pnpm build --filter=backend

# Or from this directory
pnpm build
```

## Features

- Fastify API server
- TypeScript
- Uses shared types and utilities from the monorepo
