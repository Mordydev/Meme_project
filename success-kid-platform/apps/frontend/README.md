# Frontend

Next.js web application for the Success Kid Platform.

## Getting Started

### Development

```bash
# From the root of the monorepo
pnpm dev --filter=frontend

# Or from this directory
pnpm dev
```

### Building

```bash
# From the root of the monorepo
pnpm build --filter=frontend

# Or from this directory
pnpm build
```

## Features

- Next.js web application
- TypeScript
- Integration with shared UI components
- Uses shared types and utilities from the monorepo
