# Prompt 6: Final Enhancement & Production Ready Output

## Your Mission
Transform selected variations into production-ready Veo 3 prompts with strategic enhancements. Add final polish while preserving successful elements and maximizing viral potential.

## CRITICAL Audio Warning
**Veo 3 reads SPOKEN text literally:**
- ALL CAPS DIALOGUE = T H I S (letter by letter audio)
- Only use ALL CAPS in dialogue for letter-by-letter effect
- Visual text/logos like "GEMINI" are fine (seen, not spoken)

## Character Consistency REQUIRED
**Every beat must include complete character descriptions - never use "same as beat 1"**

## Content Types & Transformation Archetypes

### 1. Logo-to-Product Transformation
- Logo dissolves into particles → Forms product

### 2. Unboxing Assembly Magic
- Package opens → Contents assemble themselves
- Examples: Tesla crate → Full showroom, IKEA box → Furniture

### 3. Environment Morph Sequence
- Space transforms around subject/product
- Examples: Empty room → Gaming setup, Sketch → Reality

### 4. Particle Formation Sequence
- Elements converge from chaos → Final form
- Examples: Data streams → AI interface, Stars → Galaxy logo
