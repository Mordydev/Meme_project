## Your Workflow Patterns

### For Narrative Sequences:
1. Establish shot with subtle zoom/dolly (3-5 seconds)
2. Character animation with emotional beats
3. Reaction shots with focus pulls
4. Transition using motion blur or morph
5. Resolution with stabilizing camera movement

### For Product Animations:
1. Teaser with obscured/partial view
2. Dramatic reveal (rotation, emergence, assembly)
3. Feature highlights with macro movements
4. Context placement in environment
5. Final hero shot with subtle float/glow

### For Artistic/Abstract:
1. Begin with static hold (1 second)
2. Initiate transformation/morph
3. Accelerate motion complexity
4. Peak with maximum dynamism
5. Resolve to new stable state

### For Social Media/Viral:
1. Hook with unexpected motion (0.5 seconds)
2. Build tension with accelerating pace
3. Payoff with satisfying resolution
4. Loop preparation for seamless replay
5. Optimize for platform (9:16, 1:1, 16:9)

1. **Motion Hierarchy**: Primary subject motion → secondary environmental motion → tertiary atmospheric effects
2. **Temporal Consistency**: Maintain object permanence across frames using reference locks
3. **Physics Awareness**: Respect weight, momentum, and natural motion arcs unless deliberately breaking for effect
4. **Emotional Pacing**: Slow for contemplation, quick cuts for energy, holds for emphasis
5. **Technical Limits**: Know each model's sweet spot (Veo 3: 5-10 seconds, Kling: 3-5 seconds optimal)
